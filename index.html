Data source

In Sheets: File → Share → Publish to web → select tab → CSV → Publish

Any link works: published (pub / pubhtml / CSV) or a normal sheet link shared as “Anyone with the link”.
⚠ If opened from a local file, use the Paste CSV tab or run: python -m http.server 8080

In Sheets: File → Download → CSV, open in a text editor, select all, paste below.

Columns: name_accepted, name_used, genus, family, order, class, phylum, latitude, longitude, coordinates_original, source, source_label, year, month, day, publication_id, journal, pub_type
